# Fitness Exercise Tracking Application 🏋️‍♂️

A full-stack fitness tracking application designed to help users efficiently organize and track their workout routines. 

##Overview
Developed to provide a robust solution for workout planning. Users can manage their exercise schedules and categorize routines based on body parts and training types. 

## Tech Stack
* **Front-end:** JavaScript, css html
* **Back-end:** Java, Spring Boot
* **Database:** Firebase

## Key Features
* **Workout Organization:** Categorize exercises by body parts and training types.
* **Routine Scheduling:** Plan and track weekly fitness routines.
* **Robust API:** Handled by Spring Boot for secure and fast data management.
